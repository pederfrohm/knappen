# Knappen (The Button) v3.1

A high-velocity, browser-based arcade game designed to gamify cognitive stress and impulse control.

## 🎮 How to Play
- **CLICK**: Tap $X$ times.
- **WAIT**: Do nothing.
- **HOLD**: Press and hold until time expires.
- **SURVIVE**: The game will lie to you.

## 🛠️ Stack
- **HTML5** (Semantic)
- **CSS3** (Variables, Animations)
- **Vanilla JS** (ES6 Modules)
- **Audio**: Custom JavaScript Synthesizer (No assets required)

## 🚀 Deployment
This project is **Vercel Ready**.
1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Done. (No build settings required).

## 💻 Local Development
Since this project uses ES6 Modules, you must use a local server:
```bash
npx serve .
```
Open [http://localhost:3000](http://localhost:3000)
